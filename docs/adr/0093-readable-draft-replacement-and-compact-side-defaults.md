# ADR 0093：可讀譯文替換與精簡側邊預設

日期：2026-10-25。狀態：採用；範圍為 Phase 11 人工驗收後的字幕可讀性與指定 UI 預設。

使用者確認 PID 5192 的 Chrome／英文／Gemini／Standard 持續播放已有中文，停止正常；快速長句的同段中文仍被新譯文整段換掉。這是該次流程的有限正例，不等於所有來源、語言或效能通過。使用者亦指定先靠右再自由移動、半螢幕高度、寬為高度三分之一、系統預設字體尺寸。

共用 TranscriptTimeline 在有舊譯文且來源 revision 改變時，先保留可讀暫定中文，不將新整段翻譯串流開頭套上。新要求 complete 才原子替換；第一版無中文時仍立即串流。先完成原有身分、順序、容量、UTF-8 與穩定前綴驗證再決定顯示，不增加本文副本、第二條時間軸或工作，Final／回退與取消規則保持。這減少短字串反覆縮掉舊段落；完整的新暫定譯文仍可改寫，不保證每次文字不變，也不將保留的暫定中文標成定稿。

側邊初始幾何使用 Windows 回報的所在螢幕實體像素，半高、三分之一寬並限制於工作區，右側定位後保持 Floating。移動、調整、設定區切換不重啟辨識；原左右停靠仍可明確選取。為符合窄視窗尺寸，主選單集中於「選單」，原固定來源／服務／金鑰區由選單切換展開；展開保留原外框、切回還原，遮蔽與安全憑證處理沿用，不新增自動連線。收合的控制項不可見，狀態與字幕各自捲動。側邊字體取 Windows 的每螢幕 DPI 訊息字體並持有／釋放自己的 HFONT；底部既有獨立外觀設定保持。

未設定內容辨識時改為「歌曲／影片辨識：未啟用獨立服務；不影響即時語音辨識與翻譯」。不把 Gemini 語音辨識宣稱為歌曲辨識、不自動配置或傳給其他服務，依既定決定仍暫緩外部歌曲服務。

本機回歸涵蓋第一版串流、後續長譯文保留／完整替換／過期更新拒收、顯示保留前的資料驗證、負座標與不同解析度、原生設定切換／Session 保留／系統字體／分框。結果另記 Phase 11；新外觀與實際長句可讀性仍需人工，不將隱藏測試視窗或 mock 當成目視驗收。
