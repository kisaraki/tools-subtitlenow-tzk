# ADR 0095：由使用者清除的有界字幕顯示紀錄

日期：2026-10-25。狀態：採用；Phase 11，依使用者明確要求更新顯示保留政策。

使用者回報 PID 22588 暫停流程基本可用，但仍偶發全字幕清空，要求不要自動清除、讓字幕往上捲，另設清除按鈕。此決定取代 ADR 0093／0094 中「停止、重連或換 Session 清空顯示」的部分；後端取消、Session 隔離、原生資源及音訊清理維持原要求。

## 顯示紀錄與後端分離

Presentation 由同一個後端 TranscriptTimeline 的快照更新一份最多 64 列的 RAM 顯示紀錄，供兩種 renderer 共用。每列保留完整 StreamIdentity（含 generation）、sequence、utterance 及已交付 UI 的有界原文／譯文。相同列只更新、不為每個 token 增列；跨連線重複段落編號不互相覆寫。滿載時只逐筆淘汰最舊列，新列往上捲動，不整批清空。每欄沿用原容量限制，不累積整份快照佇列。

停止、錯誤、重連、重新開始及來源切換不清空顯示紀錄；目前有效處理身分與版本水位仍獨立更新，晚到舊身分快照不得加入或修改紀錄。歷史只供顯示／搜尋，沒有通道送回 STT、翻譯脈絡、glossary、來源仲裁或定位。原文／譯文同段配對；不屬目前處理身分或原來源已撤回的舊文字標示「先前字幕」，底部前置標記以免最大行數裁掉標記。來源撤回造成新快照空譯文時，保留前一份配對為歷史，真實新譯文到達才更新，不續用舊來源的有效性。

這是使用者要求的本次應用程式開啟期間、顯示文字的 RAM 保留例外；不是遠端字幕／音訊快取。原始音訊、Prepared 文件、候選、指紋與 metadata 仍依處理 Session 清理，不保留或上傳供新工作重用。程式關閉即釋放顯示 RAM，不序列化、不寫設定、不保存或匯出。

## 手動清除

字幕視窗增加固定「清除字幕」按鈕，紀錄選單也可執行。窄視窗獨立一列，寬度至少 320 DIP 時放在搜尋欄旁，保留原短視窗字幕空間。按鈕不停止工作、不修改來源或服務、不更動憑證、不需額外確認。

清除重設可見紀錄、搜尋、選取及捲動；保留有效處理身分、快照版本水位與該身分已收到的最高 sequence。已清除段落及同段修訂不因下一份完整快照補回；後續新段落正常顯示，新 Session 使用獨立水位。處理所需的後端短期上下文不因 UI 清除而中斷。被清除／保留為歷史的列不得回報成新段落的 UI 呈現延遲樣本。

## 捲動與驗證

SideHistory 使用手動清除 epoch 與完整列身分對齊 UTF-16 錨點；停止／重連不重設搜尋或手動捲動。歷史標記改變標頭長度時，以本文起點還原選取，不把舊段落選到新 Session 的同號段落。

回歸涵蓋重連／停止保留、舊身分快照拒收、80 個 Session 的 64 列上限及同號更新、清除不取消／不回填／新段續顯示、來源撤回保留為歷史、真正原生按鈕及跨連線選取錨點。原有停止即清除的測試依新使用者決定改為停止保留、手動清除；未讀取的舊快照仍不得在停止後出現。具體結果見 Phase 11 診斷，不以 mock 或隱藏視窗冒稱正式服務已通過。
