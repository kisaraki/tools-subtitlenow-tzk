# ADR 0073：HTTP(S) WAVE 的明確本機外掛字幕

日期：2026-10-18。狀態：Phase 08 第四十批採用。

## 決策與原因

一般準備視窗沿用媒體網址及本機字幕欄，支援既有 PCM16 WAVE 子集合搭配使用者明確選定的本機 SRT／WebVTT。現成字幕應優先處理，不能因來源是網址便忽略文字而上傳音訊；也不把使用者聲明當成已驗證的媒體版本或播放定位證據。

新增明確 PreparedTask::run_with_remote_wave_subtitle 入口，保留舊 local-only 入口及遠端無字幕 ASR 入口的契約。控制器先進行既有 metadata-only 語言順位規劃，保留同順位歧義；所有遠端內嵌選取均先拒收，包含較低順位未選軌，不靜默忽略不支援選擇。沒有增加來源選取模式或控制項。

## 來源與字幕

只在原有有界 CPU／磁碟 worker 讀取選中的本機字幕並解析，失敗即終止，不接觸其他候選或退回辨識。解析成功後才開啟同一 HTTP owner、內容前置檢查與 canonical WAVE 標頭驗證；不呼叫 PCM 拉取、DSP 或 ASR。不依 URL 副檔名判定媒體，也不開放網站、登入、重新導向、其他遠端編碼或遠端字幕網址。

原 HTTP client、強 ETag／If-Match、來源長度、Session／generation、要求序號及原始 typed error 保持。WAVE owner 連同字幕跨分析、翻譯、completion 與 Ready 保留，並受既有兩個遠端 owner 配額限制；沒有全檔下載、預讀、媒體暫存或額外 pipeline。網路與服務等待不持 CPU 許可。來源伺服器可能於稍後變更，Ready 並非凍結遠端內容或後續播放的版本證明。

本機與遠端外掛字幕共用同一讀取／解析 helper、全文摘要／詞彙、三品質翻譯、本地化及完整結果驗證。原字幕的內容、時間與 Existing provenance 保留，沒有偽造 Recognized、識別或 alignment 證據。中文三類均在本機轉為臺灣用語，不使用服務、金鑰或語音語言；五語來源字幕只建立所選服務的分析／翻譯 client，不建立辨識器，音訊 Auto 不影響明確字幕語言。

## 介面與秘密

按準備前固定揭露來源標頭連線。中文外掛明示本機處理、不取金鑰；來源外掛明示所選實際 AI 端點及送出的選定原文、全文摘要／詞彙與翻譯前後文，不傳媒體音訊或網址。無字幕仍使用原有音訊用途揭露。私有 URL／query、路徑及本文不進目的地、狀態、通知或日誌。

固定 OpenAI／Gemini 遮蔽欄、只讀所選金鑰、取用後清空兩欄與 undo、留空讀所選 Windows 憑證、取消／清除／關閉清理均沿用。來源字幕缺服務、非法本機路徑及遠端內嵌模式於對應 preflight 拒收，不能改成 ASR。來源編輯保留手動外掛選擇；所有遠端模式仍停用字幕軌探索且直接命令有防護。

## 生命周期與驗證

沿用 caller-owned worker／runtime、有界 completion、Session／sequence 隔離、Stop／reap、Ready 鎖定及通知一次；不自動播放。預先取消、Future Drop、服務拒絕或錯誤都不發布部分文件。CPU／來源容量由真正持有者保留到實際退出，沒有新增 pool、無界佇列、unsafe、套件、遙測或永久內容。

測試使用合成 PCM、真實 loopback HTTP、本機測試字幕、明確 AI mock 與隱藏原生視窗，覆蓋來源與字幕選擇、只有標頭讀取、中文無服務、五語／品質、錯誤／取消／舊結果／配額及固定金鑰介面。實際執行結果見 [Phase 8](../phase-8.md)。正式金鑰及真實媒體／雲端品質仍留到結案固定介面手動驗收；遠端內嵌／字幕網址、其他媒體格式、五語音訊 Auto 及播放定位仍待接續，Phase 09 尚未具備條件。
