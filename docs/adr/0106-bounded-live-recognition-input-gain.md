# ADR 0106：Gemini 即時辨識的有界低音量增益

日期：2026-10-26。狀態：採用，Phase 11 低音量修正；工程檢查通過，實際小聲音源仍待人工。

## 問題與證據

使用者對 PID 31548 的 Auto 收尾修正版回覆選項 1、約五至十秒；未分別提供首次／暫停恢復的秒數，不把此估計當成 P50／P95 或達成一秒工程目標。另回報街邊等小聲錄製音源有時不啟動翻譯，追問確認 Auto 無原文／繁中，手選語言亦會發生。

程式仍原樣送出小聲 PCM；本機能量端點固定 RMS 0.003。原有完整 worker 測試以振幅 0.0005 的 500 Hz 合成訊號重現：原樣音量未啟動本機端點。這項證據不代表已確認實際錄音的音量或信噪比，也不能單獨證明服務端拒收原因。

## 決定與界線

新增不含供應商資料結構的 InputLevelPolicy，由 Gemini 串流整合明確啟用 BoundedGain，套用於 Gemini Transcribe Live（Auto／明選）及 Live Translate 的既有即時前處理 worker。OpenAI 保持 Original；Prepared、原始擷取／音量表、resolver、播放時鐘與定位證據維持原樣。沒有系統混音器操作、額外 worker、佇列、連線、金鑰或相依。

每個有效 PCM 區塊先驗證 frames、有限數值及原取樣範圍，才計算 RMS／peak；無效資料照原型別錯誤拒絕，不能限幅成有效輸入。RMS 低於 0.0002 或已達 0.03 時保留原樣；其餘增益取 0.03／RMS、16 倍、0.9／peak 的最小值且不得低於 1。增益不超過十六倍（約 24 dB），保留放大區塊的峰值餘裕，不壓低原有大聲訊號。這是有界區塊增益，不是語音分類或降噪模型；沒有額外錄音／內容保存，且不改 frames、Session、序號或時間戳記。

增益在重採樣及本機能量端點之前執行，真正傳送的 PCM 也會提高音量；不是單純讓活動旗標變成 true。診斷新增「低音量增益」前處理封包數，純數值且 Session 內重設；它不代表服務收到、辨識或翻譯成功。既有音訊年齡、佇列上限、語言核對、真正 final、翻譯三秒期限及取消保持。

## 驗證與限制

檢查增益上限、正常音量／零值／極低訊號不變、峰值、NaN／Inf／超界拒絕、有效 frames 之外不讀寫、完整身分與時間保留；原 worker 以 16／24 kHz 比較 Original 與 BoundedGain，Original 對照原重採樣結果逐樣本相等。以 localhost WebSocket 檢查 Auto 與明選英文真正送出的合成 PCM 已放大，數值進度、無媒體時間及取消保持。

區塊增益會一併提高背景聲，無法分離街邊噪音中的人聲；低於保護下限的訊號不保證觸發。真實小聲錄製音源的辨識／翻譯與實際速度仍須人工驗收，不能把合成服務的回覆當作雲端準確率或延遲證據。

最終 119 項定向含五項新增，獨立串行完整回歸 2140 一般成功、零失敗、18 ignored；格式／零警告 Clippy／Debug／Release 通過。已備份與更新標準版並開啟待命，完整數據、fixture 修正及部署雜湊見 [診斷紀錄](../phase-11-gemini-diagnostics.md)。
