# ADR 0072：一般 Prepared 視窗的 HTTP(S) WAVE 入口

日期：2026-10-17。狀態：Phase 08 第三十九批採用。

## 決策

沿用一般 --ui 準備視窗的媒體輸入欄，標示「本機完整路徑／HTTP(S) WAVE 網址」。只有明確的 http://／https:// 前綴（不分大小寫）選擇遠端來源，其餘仍按原有本機路徑驗證；沒有副檔名、檔名或網站猜測，也不自動修復／trim。完整 URL 仍經 MediaInput::remote 的語法、容量及權限邊界驗證，辨識 codec 依內容 gate，不依 .wav 後綴。

這次沿用單一欄位，是因為明確 URL scheme 已能區分使用者選擇，避免新增模式與另一組私人來源文字。控制項數量、順序與布局不變，本機預設流程及既有字幕選擇保持。沒有在輸入網址、選服務或更新揭露時連線；只有明確按準備才啟動工作。

## 來源與服務

PreparedController 先做 metadata-only 的字幕規劃，保留同順位歧義錯誤；遠端加任何選定文字的組合在 Session、worker、服務／金鑰取用之前拒收。原生視窗也先拒收非空字幕欄或內嵌模式，包含空白字元與缺少軌 ID，不能把它們當成無字幕而上傳音訊。手動字幕不隨網址變更而默默移除；原有來源變更會退休探索及自動軌 ID。

遠端無字幕仍需明確五語與所選服務，Auto 在認證或連線前拒收。沿用同一個 caller-owned 背景 worker／Tokio runtime、所選服務 factory 與一次金鑰解析。Recognition 分支依來源選擇既有 remote 或 local PreparedTask；不是新增另一條語音／全文處理管線。遠端使用既有16 kHz預處理，沿用摘要、詞彙、三品質翻譯、本地化及本次 RAM Ready。

MP4 字幕探索保持本機限定：遠端時停用按鈕，直接或過期命令也先拒收，沒有啟動探索 worker／連線。服務 factory 及 recognizer 的能力、HTTP／內容／PCM gate、來源版本錯誤與配額均沿用既有契約，不改為下載整份或繞過登入、重新導向與保護。

## 使用者揭露與秘密

固定可見的揭露先說明按準備會連線至輸入的媒體網址，再列出實際所選 AI 端點及送出的短片段音訊、辨識原文、全文摘要／詞彙與翻譯前後文。網址不加入 AI 請求，也不複製至目的地、狀態或完成通知；來源輸入本身仍可見。格式提示以使用者能判斷的直接 PCM16 WAVE、單／雙聲道及不支援網頁／登入／重新導向說明，完整技術限制沿用 ADR 0067–0069。

ChatGPT／OpenAI 與 Gemini 維持固定獨立遮蔽欄。只取所選欄位，兩欄在開始／錯誤／探索嘗試／取消／清除／關閉按既有規則清空與移除 undo；留空才由背景讀取所選安全憑證。沒有自動儲存、新服務、跨服務 fallback 或正式金鑰測試。HTTP(S) 是使用者明確輸入的原 scheme，不暗中降級 HTTPS。

## 取消、容量與驗證

沿用單一 worker、有界 completion、Stopping／reap、Session／generation 隔離與 Ready 鎖定；關閉等真正工作退出。錯誤保留 typed cause，URL／query／金鑰不進錯誤文字。沒有新增相依、pool、音訊／文字快取、錄音、下載輸出、匯出、播放或第二份時間軸。

controller 以自有 PCM、真實 loopback HTTP 及明確 factory／AI mock 驗證兩個所選服務、三品質、金鑰路由、錯誤、停止、舊回覆與重新啟動；原生隱藏視窗測試揭露、遮蔽／清除、輸入拒收、探索鎖定與 Ready。既有字型度量案例另涵蓋遠端揭露的窄視窗與雙倍字型，不外推成真人多螢幕驗收。實際結果見 [Phase 8](../phase-8.md)。

目前只開放既有 PCM16 WAVE 子集合；一般網站、遠端壓縮格式、URL 搭配可靠字幕、五語 Auto、真實媒體／語意／雲端及播放仍待接續。正式金鑰維持結案固定介面手動輸入。Phase 09 尚未具備啟動條件，達標時會提醒。
