# ADR 0097：主頁操作、獨立服務設定與字幕自動跟隨

日期：2026-10-25。狀態：採用，Phase 11 人工介面修正。

## 原因

使用者回報前版五分鐘以上持續翻譯、停止及紀錄保留正常，但仍覺得慢，並要求服務／金鑰獨立且可儲存、主頁固定開始／停止／清除、設定原位開啟，以及修復直式字幕不再跟隨最新內容。

既有設定展開會強制靠右；既有 EN_VSCROLL 處理無法分辨程式重排與使用者輸入，在非 refresh 階段收到通知便停用跟隨。本機模擬一份原生 EDIT 捲動通知即可重現第二段後 auto_follow=False，不能據此把所有真實播放器延遲歸因於顯示。

## 決定

以 Subtitles／Sources／Credentials 三個互斥頁面管理同一主視窗。選單分為「來源設定／回到字幕主頁」與「服務與金鑰設定／回到字幕主頁」。來源頁保留所選程序、活動、語言、品質及本次字幕／Prepared 入口；服務頁保留服務選擇、固定雙列遮蔽金鑰、各自儲存／本機檢查及 Gemini 無音訊診斷。切頁不重啟後端、不清字幕或丟棄所選來源。

「儲存服務與偏好」只儲存已選服務、來源語言及品質；沿用既有有版本 config schema、容量限制及原子寫入，保留其他既有偏好。沒有來源也能儲存，不讀取金鑰欄、不啟動服務或音訊、不保存程序識別與字幕。金鑰仍只由具名供應商的各列按鈕寫入 Windows 認證管理員；既有寫入後確認、欄位及 undo 清除不變。繁忙或 modal owner 停用時不受 posted command 繞過。

既有開始及停止 child button 成為所有頁面均可見的主操作區，與清除字幕一起顯示；啟用／取消規則保持原樣。340 DIP 以上三顆同列，較窄主頁以開始全列、停止與清除同列，確保原尺寸可閱讀與操作。設定第一次展開保留原字幕外框，以目前左上角擴至至少 680×720 DIP、受目前工作區限制；只有必要時夾回工作區，切換設定頁不覆寫還原框，返回主頁還原原外框。

EN_VSCROLL 不再代表人工操作。只在本視窗 EDIT 的 subclass 觀察滑鼠滾輪、捲軸、點選或導覽鍵，才停用自動跟隨；程式更新、重排及捲到底部不取消跟隨。refresh／layout 使用可巢狀還原的同步旗標，保護原生重入。subclass 僅在擁有該 HWND 的 UI thread 存取穩定 Box 位址，NCDESTROY 撤除；callback 不讓 panic 穿越 ABI，永遠只呼叫一次下一層程序。手動回看仍保持原 UTF-16 錨點，回到即時字幕實際捲到底部；64 筆 RAM 歷史及使用者手動清除政策不變。

## 驗證與限制

明確 mock／隱藏原生視窗驗證 90 段跨歷史淘汰後仍跟隨，程式通知不會停用、實際手動 scroll 會停用、回即時會抵達原生 scroll range 底部；另驗證兩設定頁可見性、原位展開、三主操作常駐，以及無來源且有未儲存合成金鑰時只儲存非秘密偏好。既有金鑰遮蔽／幾何／undo／隔離檢查改在獨立服務頁執行，不移除安全斷言。暫存測試設定檔核對重開載入、保留 display mode、無額外鍵值與 temp 殘留，無服務及不支援 schema 不覆蓋原檔。

這批修復畫面跟隨及操作流程，未調整雲端模型、Standard 預設、三品質策略、三秒翻譯期限、擷取時鐘、來源仲裁或並行上限。正式辨識／翻譯速度仍需實機量測；不能把這些本機測試當成遠端延遲改善的證據。沒有新依賴、worker、遙測、內容落盤或第二份時間軸。實際驗證見 Phase 11 診斷。
