# 原生字幕視窗外觀更新

## 深色／淺色面板（2026-11-02）

使用「選單 → 面板外觀」切換。預設淺色，選擇立即生效並獨立儲存；不用先設定 AI 服務。主面板及其設定頁、狀態視窗、關於視窗使用一致配色。Windows 原生選單與系統對話框保留系統樣式；底部字幕仍沿用原本獨立的文字與透明度設定。

| 模式 | 背景 | 主要按鈕 | 重點色 | 停止／清除 |
| --- | --- | --- | --- | --- |
| 深色 | 藍黑 `#0B1220`、`#121E32` | 螢光綠 `#B7F34D` | 紫羅蘭 `#B39AF6` | 琥珀 `#F6BC52` |
| 淺色 | 灰 `#F4F4F7`、白 `#FFFFFF` | 紫羅蘭 `#6740AF` | 紫羅蘭 `#6740AF` | 橘 `#B54A13` |

切換不替換文字、不重建控制項、不改變視窗位置或字型、不呼叫開始／停止翻譯。下拉選單保留原生名稱、鍵盤與選取功能，使用同組色彩繪製選項。高對比模式優先使用系統色，支援的 Windows 標題列會配合深淺色；不使用未公開的 dark-mode API。

偏好 schema 3 新增 `panel_theme`。舊設定只在 RAM 遷移，明確切換才寫回；只更新配色、不讀取憑證、不覆寫未儲存的服務選擇。寫入失敗保留本次配色並顯示錯誤。

GitHub Pages 官網右上角提供「淺色／深色」按鈕，共用上述主色。首次依 `prefers-color-scheme` 選色，手動選擇優先並以網站專用 localStorage 欄位保存；瀏覽器禁止儲存時仍能切換本次配色。這項網站偏好與桌面設定各自保存，不同步到伺服器。按鈕保留鍵盤操作、可見焦點與 `aria-pressed` 狀態。

## 實作邊界

`src/win32/subtitle_theme.rs` 集中管理 UI 色彩、brush 與原生按鈕繪製。Theme 及其 GDI 物件只存在 UI 執行緒，主視窗與子視窗銷毀後才釋放；繪製前後儲存／還原 DC。只讀取固定按鈕標籤，不讀取金鑰或字幕本文。

開啟 Windows 高對比模式時使用系統配色，系統查詢失敗時亦採系統色。收到系統色彩／主題設定通知時重建樣式並重繪；外觀更新失敗不停止翻譯。只增加既有 windows crate 的 Accessibility API feature，沒有安裝新元件或新增外部相依套件。

控制項仍是原生 BUTTON／EDIT／COMBOBOX，保留名稱、命令 ID、鍵盤及輔助使用行為。來源、語言、品質、主操作、狀態／字幕分框、手動清除與歷史跟隨政策保持。未讀取正式憑證或啟動音訊／雲端測試。
