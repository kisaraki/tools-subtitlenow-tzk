# 臺灣繁體中文輸出

0.1.4 起，共用翻譯輸出強制套用臺灣繁體字與臺灣常用詞彙，再交付單一字幕時間軸；側邊紀錄、底部字幕及雙模式使用相同譯文。

- Live 翻譯的 `TranslationEmitter` 統一處理串流暫定、完整結果與 High 校訂，不再只依賴服務 adapter 的實作。
- Gemini 原生直譯維持既有本機轉換，真正定稿前仍為暫定文字；Prepared 與既有字幕／歌詞共用同一套內建 OpenCC 臺灣詞彙資料。即使來源標記為 zh-TW，也核對並轉換顯示副本。
- 共用模型指示明訂 zh-TW、臺灣語法及詞彙，來源內容不能覆寫目標語言。本機字典補強字形與詞彙，模型仍負責語意翻譯。
- 例如「内存、软件、服务器、文件夹、鼠标」轉為「記憶體、軟體、伺服器、資料夾、滑鼠」。英文專有名稱、數字與原文欄位保留。
- 轉換前後都核對 8 KiB 單段上限。穩定前綴在轉換後比對，定稿使用轉換後的 UTF-8 位元組長度，避免「内存 → 記憶體」變長時拒收合法定稿或錯誤切字。
- 維持既有 Session／generation／修訂檢查、取消、三秒 Live 期限及有界佇列。轉換不在擷取 callback 或畫面重繪執行，不新增雲端要求、內容落盤或快取。

回歸測試涵蓋未自行轉換的 mock translator、三種品質、串流／定稿／校訂、已提交前綴、轉換膨脹超限、原生直譯，以及錯誤標記為 zh-TW 的混合繁簡字幕。這些測試驗證本機轉換與交付路徑，不代表已重新驗收所有真實雲端翻譯的語意品質。

### 連續說話時的文字翻譯

相容的暫定原文在上一筆要求執行期間開始累計合併時間。Fast、Standard、High 的間隔分別為 60、160、300 毫秒；間隔已滿且有可用名額時，直接送出最新版本。每個版本仍受原有三秒期限約束。服務重送相同文字時略過重複的暫定更新；若完成事件修正譯文，採用修正結果再定稿。

文字翻譯要求會標記原文是片段或定稿，讓模型在未完句保留語意空間，並在定稿時核對否定、數量及單位。2026-11-28 的 OpenAI Standard 小樣本以英、日、法、德、韓各一句表達「不要刪除三個檔案」，五句定稿都保留否定、刪除動作、數量與檔案。此檢查涵蓋文字翻譯的指定語意，不衡量整體辨識準確率。

最後建置的五語文字測試從送入原文到第一段非空譯文為 477–772 毫秒，定稿為 599–858 毫秒。另以 Windows 程序音訊擷取測試 Release 執行檔，英文合成語音連續播放三句、重複三輪，共九段在同一工作階段正確定稿，涵蓋否定、檔案數、印表機離線與十二分鐘後重新啟動伺服器。語音案例未量測從開口到螢幕顯示的總延遲。
