# ADR 0026 — 文字準備沿用工作階段出版物與獨立取消範圍

日期：2026-10-10。狀態：Phase 7 第五批採用。

Live 的歌詞管理先前只提供純狀態，無法把已驗證查詢文字交給準備入口。直接分享可寫字串或只複製本文又會失去來源生命週期。因此加入封裝 ExistingTextLease：只從 Available 出版物建立，query／文字為唯讀 Arc，清除及停止撤銷 parent，舊 handle 不能繼續提交。

相同歌曲的文字在 active Session RAM 可以重用，不應因每個翻譯視窗重新查詢。只有新的明確 Confirmed 捕捉證據能建立新選取 query；舊 handle 的時間不變，沒有以 poll、回覆時間或牆鐘延長期限。確認信心沿用服務分數，下降撤銷舊 handle，準備與提交不能將它提高。

TextPreparationSession 借用已選定的 Translator，同一 CPU lane 處理中文及翻譯後本地化，來源語言使用既有有界視窗與品質策略。它只準備候選，呼叫端仍須提供實際定位證據才可提交原有 Live 仲裁／時間軸，沒有將查詢成功視為同步成功。

查詢出版物、準備管理物件及單一仲裁候選是不同生命週期。將同一取消 token 交給它們，會使候選淘汰反向取消共用查詢，或使準備停止後的結果重新出現。因此保留候選自己的 token，另追蹤固定兩個 parent；取消不產生監看 task，也不需要無界取消樹。準備停止與出版物撤銷立即使讀取失效，資源由既有 caller-owned future 及 CPU join 回收。

新增有界文字介面不啟用正式 GUI 的內容服務、定位或自動雲端傳送；實際定位與候選排程仍待組合。所有文字及脈絡只在工作階段 RAM，沒有持久快取或匯出。
