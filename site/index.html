開始使用

三個步驟，
準備好閱讀。

安裝程式會偵測同一產品的已安裝舊版，先解除安裝，再安裝新版。設定與 Windows 認證管理員中的金鑰會保留。

  1. 下載並安裝

    執行 setup.exe。安裝至目前使用者帳戶，從開始功能表開啟 SubtitleNow。

  2. 設定服務與金鑰

    在「選單 → 服務與金鑰設定」選擇 OpenAI 或 Gemini，輸入對應 API 金鑰。請依所選模型的提示選擇語言。

  3. 選擇來源，開始翻譯

    確認聲音來源、語言與品質後，按下「開始翻譯」。日後可從「關於」檢查更新並下載安裝。

清楚的資料界線

聲音只為這次字幕服務。

程式不提供錄音儲存、永久字幕快取或字幕匯出。音訊與辨識／翻譯文字會依你的設定送往所選雲端服務，使用前請確認其資料處理政策。

不加入使用分析追蹤。只有按下「檢查更新」才會向 GitHub 查詢版本，更新要求不包含音訊、字幕或 API 金鑰。
