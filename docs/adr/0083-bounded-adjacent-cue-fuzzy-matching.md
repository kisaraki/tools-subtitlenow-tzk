# ADR 0083：有界的相鄰雙段模糊定位

日期：2026-10-23。狀態：Phase 09 第七批採用。

## 決策與原因

ASR 分句常與字幕 cue 邊界不同，單段搜尋會漏掉一句對應兩段的情況。本批在原搜尋核心內比較每個單段及每個相鄰雙段，不另建定位器、第二份文件或工作管線。N 段文件最多比較 2N−1 個詞彙候選；8192 cues 時最多 16,383 個，所有候選共用原有 2,097,152 DP cells、三秒工作及原窗口五秒期限。

原 Final ASR 與每個原始 cue 的正規化上限仍是 256 Unicode scalar。雙段由兩個已驗證且有界的正規化緩衝區加入一個明確空白邊界，最多 513 scalar；每 cue 只正規化一次，只保留上一段、本段與暫時合併結果，不複製整份原文。DP 的右側陣列固定 514 格；以文字長度下界或既有 850 下限排除不可能競爭者，不能以裁切或跳過超量原始 cue 製造唯一結果。後段原始 cue 超過 256 仍使整次失敗，即使前面已找到勝出者。

只正規化空白與 ASCII 大小寫；空白邊界、標點、重音與 Unicode scalar 保留，不合併非相鄰段、不支援三段以上或任意子字串。日文／韓文也保留相鄰邊界的一個空白，由實際編輯距離計入，不無條件抹除字界。

## 全文歧義與時間

單段與雙段參加同一次全文件排名，沿用 900／50／850 門檻與至少 16 個字母／數字。重疊雙段仍是不同候選，不能合併票數；另一單段或遠處雙段同分／差距不足就 NoUniqueMatch。雙段即使缺時間、相隔很遠或重疊，仍參與詞彙競爭，不能先依猜測播放區間或時間排除以提高唯一性。相鄰短片段可能形成接近的另一候選而保守拒收，沒有偏袒單段或偷偷忽略競爭者。

唯一勝出者若為雙段，兩段必須各有完整正時間、按原順序互不重疊，間隙最多 500,000 微秒（包含邊界）。超過間隙或缺時間回 TimingMismatch，不回退至較弱單段。這是工程門檻，非播放驗證。media range 原樣保留第一段起點至第二段終點，包含間隙；capture range 保留 ASR 原區間，不裁剪或生成假 stamp。

`FuzzyCueProposal::cue_range()` 新增半開原始 cue 索引範圍；既有 `cue_index()` 保持第一段索引，不再代表完整涵蓋。所有正式呼叫者保留完整範圍，既有多觀測追蹤以 `new.start >= old.end` 核對 cue 不重疊，避免共享一段的雙段配對算成獨立支持。範圍改變也參與同 binding 資料一致性比較。

## 來源、生命週期與範圍

ExistingText 與 sealed PreparedRecognition 共用同一核心，來源種類、獨立文件／擷取 Session、generation、epoch、Final binding、取消與原期限維持。相鄰 ASR cue 只借用原文與原生媒體時間，不包裝成來源字幕。Ready 弱文字 owner、媒體 pin 分離、四祖先取消、共享 CPU／單 locator 一項、最新要求管理與軌跡快照撤回都沿用；沒有新服務、runtime、worker、thread、queue、依賴、unsafe、金鑰取用或產品內容寫入。

結果仍是 FuzzyCueProposal／時間一致性提示，不轉成 ExactCueMatch、CandidateEvidence、經驗證錨點或目前播放位置；ExactCueVerifier、來源仲裁、LivePlaybackClock 與 TranscriptTimeline 不改接。中文參考軌、三段以上、可靠錨點、位置／seek／pause／restart、offset／drift 及一般 Live／GUI 自動接線仍待後續。Phase 10 尚未具備條件；正式金鑰與真實雲端維持結案固定遮蔽介面手動驗收。

## 驗證

合成核心測試涵蓋完整雙段索引及範圍、單段保留、跨型別／遠處／缺時間／重疊雙段歧義、時間間隙邊界、缺時間與重疊拒收、非相鄰／三段拒收、五語字界、513 上限、後段超量失敗、共用 DP 精確預算及擴大陣列與 unrestricted oracle 比較。sealed Recognized 測試核對原生時間／來源與跨 chunk 遠處重複。

實際 worker／最新管理器與追蹤測試核對三個不重疊雙段的累積、共享 cue 不重複計數、停止撤回及 CPU 回收；真正本機合成 SRT Ready 經明確 Translator mock 核對零額外服務、停止後文字與媒體釋放。這些是合成／mock 工程證據，非真實播放或辨識品質驗收。實際結果見 [Phase 9](../phase-9.md)。
