# ADR 0096：隔離 Live 單次翻譯逾時

日期：2026-10-25。狀態：採用，Phase 11 人工穩定性修正。

2026-10-27 補充：單次 Live Incomplete 也納入有界要求隔離，並明確區分非過期計數與服務拒絕；見 [ADR 0110](0110-isolate-incomplete-live-translation-requests.md)。以下保留本批原始期限隔離設計。

## 原因

使用者確認手動清除、停止保留及重新開始上捲正常，但數分鐘後出現「翻譯要求逾時，未顯示過時結果」。本機明確 mock 在第一段回傳 Timeout、後續正常即可重現舊流程立刻取消整個翻譯 Session；原要求總年齡三秒、傳輸及要求期限均不延長。此重現證明錯誤傳播路徑，不能證明正式服務當時的網路或處理延遲根因。

## 決定

只有 LiveTranslation 使用要求層級的 Timeout／Stale 隔離；一般 TranslationJob::run 與 Prepared 保持原本失敗即取消的契約。Live 以完整 Session／generation、utterance、來源 revision、sequence、pass、job id 核對過期工作，只退休目前這一份工作。取消其 token、釋放 permit、清除其 job id，拒收尚未套用的舊輸出，保留已顯示的 Tentative 文字，不冒充 Final 或完成成果。被較新來源修訂或既有字幕取代的工作不得退休新要求，也不得累計成新的延遲事件。

Live 排程前捨棄已過期的待譯項目；合併槽也沿用原絕對期限，過期不送出。跳過的合併修訂保留有界 revision 水位，重複舊 revision 不能重新取得期限。只接受新的來源修訂或後續段落，不重送同一份過時要求，不增加佇列或 API 並行、不放寬來源／時間定位證據。

單一連線只持有一份數值警告：最近段落號、總捨棄次數、連續失敗數與固定型別原因。狀態框明示該次未完成翻譯已捨棄，後續新段仍持續處理；一份有效的 complete 翻譯通過原本來源／job／前綴核對並套用後才歸零連續失敗數，警告保留累計並顯示後續已恢復。Partial 不歸零。連續第三次期限失敗仍使 Session 失敗，交回原本語音／翻譯共用的三次有限復原與退避；憑證、格式、網路、限流、拒絕等其他錯誤維持原處理，不切服務。

警告獨立於字幕快照，不清字幕、不推進媒體時間、不回送歷史文字；begin／terminal／重連清掉前一連線警告，拒收舊 Session 警告。CLI 使用固定訊息及數值 warning，不含來源本文、翻譯本文或金鑰。顯示歷史仍依 ADR 0095，只供使用者查看。

## 驗證與限制

回歸涵蓋真正要求期限取消永不完成的 mock、permit 釋放、排隊舊 partial 拒收、已套用 Tentative 保留、新修訂與外來身分隔離、後續段落正常完成、連續三次升級、其他錯誤立即失敗、合併期限及修訂防回補、停止，以及一百段中十四次間歇逾時仍維持原 64 列容量。UI mailbox 另核對狀態警告與快照分離及跨 Session 拒收。

這會明確捨棄該次未完成翻譯，不能補回已逾時的中文，也不保證遠端服務一定恢復。固定介面的 Chrome／英文／Gemini／Standard 多分鐘人工驗收仍需完成；測試結果見 Phase 11 診斷。沒有新增套件、unsafe、worker、音訊擷取、內容落盤或遙測。
