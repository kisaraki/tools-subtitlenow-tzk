# Phase 5 驗收狀態

本表區分已實作、離線／原生查詢與實際操作。未通過的欄位不可推論為已驗收。操作方式見 [測試程序](phase-5-test-procedure.md)。本機基準仍為 Windows 10 19045，正式金鑰與真實雲端依使用者安排留至結案手動輸入。

| 項目 | 程式與本機檢查 | 仍待驗收 |
| --- | --- | --- |
| SideChat／BottomSubtitle／Dual | 同一 timeline、模式切換、Session／版本隔離與原生控制項測試通過 | 真實字幕連續性、視覺可讀性 |
| 來源、服務、五語／Auto、品質與開始／停止 | 唯讀探索接線、來源身分、取消／join、RAM 金鑰清除與原生 mock 操作通過 | 正式服務五語／品質、實際應用程式矩陣 |
| 固定 OpenAI／Gemini 金鑰介面 | 獨立遮蔽欄位、明確安全儲存動作、開始清空／undo、長度與型別檢查、錯誤狀態及 busy 鎖定已實作；原生 mock 測試通過 | 有效金鑰手動操作、正式服務權限、真實鍵盤／視覺矩陣 |
| 來源圖示／活動／峰值／音量／靜音 | 原生圖示像素、未知資料處理、選項保持、重用 PID 不沿用通過 | 實際來源圖示、連續音量變化、各應用程式 |
| 搜尋／回看／回到即時 | 共用模型、搜尋同步清除、更新／歷史淘汰／狀態文字變更時保留項目與選取、超過 65,535 字元的 UTF-16 索引及返回底部通過；搜尋有獨立可見標籤 | 修正後的輔助工具名稱、真實鍵盤／滑鼠與回看操作 |
| 主視窗最小化／恢復 | 自有原生 mock 視窗：最小化隱藏 overlay、保留正常控制項尺寸與更新中的回看項目，恢復顯示；最小化來源提示不放行啟動門檻 | 真實前景／鍵盤焦點、工作列、播放器及雲端長時間操作 |
| 字型／字級／描邊／陰影／透明度／行數 | 有界像素合成、字形／行數裁切與原生選單通過 | 字形完整性、長字幕、不同背景的可讀性 |
| 拖曳／鎖定／穿透 | 原生 hit-test、layered style 與位置保持通過 | 真實滑鼠、透明區域與播放器互動 |
| 左右停靠與自由移動 | 負座標／五種 DPI 幾何、原生定位／Session 保持通過 | 各螢幕、拖移、不同 DPI 與小工作區域 |
| 主螢幕／指定螢幕／跟隨來源 | 原生清單、已驗證 PID → HWND → 螢幕查詢與失敗提示通過 | 雙螢幕／混合 DPI、實際播放器、多視窗與來源最小化 |
| 視窗資源回收 | 隔離程序 60 次隱藏 GUI 循環：三批 GDI 3、USER 2，暖機後無成長 | 長時間真實 backend／capture、完整關閉／失敗矩陣 |
| UI／端到端延遲 | 尚未完成真實量測；33 ms 通知節流僅為設計值 | P50／P95／最大值、丟棄與重新連線 |
